# GUI-BASED-GAME-IN-JAVA 🎮

A text-based adventure game with a graphical user interface built in Java using Swing. Navigate through a fantasy world, make meaningful choices, and face off against monsters in this interactive story-driven game.

## 📋 Overview

This is a GUI adventure game where players explore different locations, encounter NPCs, battle enemies, and collect items. The game features:

- **Interactive Story**: Branching narrative with multiple choices at each location
- **Combat System**: Fight enemies with different weapons and varying damage
- **Inventory Management**: Collect weapons and items that affect gameplay
- **Health System**: Manage your HP throughout your adventure
- **Multiple Locations**: Explore towns, crossroads, forests, and more

## 🎯 Game Features

### Locations
- **Town Gate**: Meet a guard at the entrance to a mysterious town
- **Crossroad**: A junction leading to different adventures
- **North**: A peaceful river where you can rest and recover health
- **East**: A forest where you can find better weapons
- **West**: Where you encounter a goblin for combat

### Combat System
- **Weapons**: Start with an AXE, upgrade to a Long Sword
- **Damage Calculation**: Weapon type determines damage range
  - AXE: 1-5 damage
  - Long Sword: 9-15 damage
- **Enemy AI**: Monsters deal random damage (3-8 HP)
- **Victory Condition**: Defeat the goblin to obtain the Silver Ring and win the game

### Player Stats
- **HP**: Start with 25 health points
- **Weapon**: Affects damage output in combat
- **Items**: Silver Ring is needed to complete the story
